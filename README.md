## Sobre o projeto 
   - [É um jogo simples, onde o jogador controla um gatinho mago em uma floresta e deve coletar todas as páginas espalhadas por ela.]
## O que o projeto faz -
   - [O jogador pode se movimentar livremente usando as teclas WASD.]
   - [O jogador pode pular usando a tecla ESPAÇO.]
   - [Ao tocar nas páginas, elas somem e o placar atualiza com o contador.]
   - [Quando todas são coletadas, aparece o texto de vitória.]
## O que o projeto contém - 
   **Cenas:** [ForestScene] 
   **Scripts:** 
   - [Movement.cs - É o código que gerencia a movimentação e pulo do jogador, bem como sua interação com coletáveis.]
   - [Colletable.cs - Faz a função dos coletáveis sumirem e adicionarem os pontos ao placar ao serem coletados]
   - [Rotate.cs - Faz os objetos rotacionarem no próprio eixo (como nos coletáveis).]
   - [GameManager.cs - Gerencia os textos de contador, vitória e derrota, bem como atualiza eles quando necessário.]
   - [CameraFollow.cs - Faz a câmera seguir o jogador a todo momento.]
   **Objetos principais:**
   - [Jogador, Walls, Pages parent, Tree, Canvas, Arbusto] 
   **Recursos usados:**
   - [Collider nos objetos(Mesh Collider, Sphere Collider, Box Collider, Capsule Collider), Collider com Is Trigger, TextMeshPro, Character Collider] 
   ## Controles - 
   - [W] – [Anda para frente]
   - [S] – [Anda para trás]
   - [A] – [Anda para a esquerda]
   - [D] – [Anda para a direita]
   - [Espaço] – [Pula]
